# Курс "Программирование (ТОП-ИИ)"

В этом репозитории хранятся выполненные домашние задания и практические работы по курсу программирования.

## 📁 Структура проекта

Репозиторий организован по принципу: **одна папка = одно занятие**. 
Папки названы в формате `ГГГГ-ММ-ДД` для хронологической сортировки.

## 🚀 Инструкция по запуску

Если внутри папки с заданием есть файл `requirements.txt`, перед запуском скриптов необходимо развернуть локальное окружение.

**Порядок действий в терминале:**

```bash
# 1. Перейдите в папку нужного занятия
cd НАЗВАНИЕ_ПАПКИ

# 2. Создайте и активируйте виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# 3. Установите зависимости
pip install -r requirements.txt

# 4. Запустите нужный скрипт
python3 имя_файла.py
