# Курс "Программирование (ТОП-ИИ)"

В этом репозитории хранятся выполненные домашние задания и практические работы по курсу программирования.

## 📁 Структура проекта

Репозиторий организован по принципу: **одна папка = одно занятие**. 
Название каждой папки соответствует дате (например, `02.10.26`, `09.10.26`).

Внутри папки занятия находятся:
* `*.py` — скрипты с решениями задач.
* `requirements.txt` — список сторонних библиотек (если они требовались в конкретном задании).
* Вложенные папки (например, `task0_calculator/`) — для задач, состоящих из нескольких модулей.

## 🚀 Инструкция по запуску

Проекты используют локальные виртуальные окружения. Если внутри папки с заданием есть файл `requirements.txt`, перед запуском скриптов необходимо развернуть окружение.

**Порядок действий в терминале:**

# 1. Перейдите в папку нужного занятия
cd НАЗВАНИЕ_ПАПКИ

# 2. Создайте и активируйте виртуальное окружение
python3 -m venv venv
source venv/bin/activate  # Для macOS/Linux
# venv\Scripts\activate   # Для Windows

# 3. Установите зависимости
pip install -r requirements.txt

# 4. Запустите нужный скрипт
python3 имя_файла.py
